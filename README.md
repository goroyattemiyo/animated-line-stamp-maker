# Animated LINE Stamp Maker

AIが生成した8フレームの画像シートを、LINEアニメーションスタンプ用APNGへ整えるローカル制作支援ツールです。

## v1のゴール

**横4列×縦2行の8フレームシート1枚を読み込み、他の画像編集ソフトを使わずに、LINEへ申請できるAPNGを1個完成させる。**

```text
GPTで8フレームシートを生成
  ↓
本アプリへ読み込む
  ↓
分割・トンボ除去・位置調整
  ↓
速度・順番・ループを調整
  ↓
プレビュー
  ↓
LINE仕様に合格したAPNGを出力
```

## v1の完成条件

次の操作を一つのアプリ内で完了できればv1完成とします。

1. PNGシートを読み込む
2. 横4列×縦2行へ自動分割する
3. トンボ領域を除去する
4. 各フレームの位置を手動調整する
5. フレーム順・表示時間・ループ回数を設定する
6. 白・黒・透明背景で動作確認する
7. LINE向けサイズへ変換する
8. APNGを書き出す
9. 書き出したAPNGを再検査する
10. フレーム数・再生時間・寸法・透過・容量が合格したことを表示する

## v1でやらないこと

- キャラクター画像の生成
- 手・顔・文字などのAI修復
- AIフレーム補間
- 高度な背景除去
- 8個・16個・24個のセット一括管理
- メイン画像・タブ画像・申請ZIPの生成
- LINE Creators Marketへの自動アップロード
- クラウド保存
- macOS・Linuxの正式対応

作画崩れはGPT側で再生成し、本アプリは機械的に再現できる整形だけを担当します。

## 基本入力仕様

- PNG画像1枚
- 横4列×縦2行
- 合計8フレーム
- フレーム順は上段左から01〜04、下段左から05〜08
- 背景は透明
- 各セル外周に、後で除去するL字マーカーを配置可能
- 画像内にフレーム番号を描かない

## 設計方針

- 固定4列×2行を主判定とし、トンボは補助に使う
- 元画像を上書きしない
- 自動位置補正を勝手に適用しない
- 同じ入力と設定から同じ出力を再現する
- APNGを書き出した後に必ず再検査する
- 主要処理はオフラインで完結する
- Windows版を先行する

## 将来のv2候補
