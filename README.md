# Animated LINE Stamp Maker

1枚の透過PNG画像から、LINEアニメーションスタンプ用の8フレームAPNGを作るブラウザアプリです。

## Webアプリ

https://goroyattemiyo.github.io/animated-line-stamp-maker/

画像はアップロードせず、ブラウザ内だけで処理します。

## v1のゴール

**キャラクターPNGを1枚読み込み、動きテンプレートを選び、プレビューして、LINE向けAPNGを1個完成させる。**

```text
透過PNGを1枚読み込む
  ↓
透明余白を自動検出
  ↓
動きテンプレートを選ぶ
  ↓
8フレームを自動生成
  ↓
強さ・サイズ・位置を調整
  ↓
アニメーションプレビュー
  ↓
LINE仕様を確認
  ↓
APNGを書き出す
```

## 現在できること

- PNGの選択とドラッグ＆ドロップ
- 透明領域とキャラクター範囲の検出
- 8フレームの自動生成
- 7種類の動きテンプレート
  - ぴょこ
  - ゆらゆら
  - ぷるぷる
  - ぺこり
  - ぽよん
  - ふわふわ
  - くるり
- 動きの強さ、画像サイズ、X・Y位置の調整
- 透明・白・黒・グレー背景でのプレビュー
- 1〜4秒のループ時間設定
- 合計4秒以内のループ回数設定
- 現在フレームのPNG保存
- 320×270px・8フレームのAPNG生成
- APNGのフレーム数とループ回数の再検査
- 1MB容量チェック

## 技術構成

## v1でやらないこと

- 手足の自動パーツ分割
- ボーンアニメーション
- 瞬き・口パク用パーツの差し替え
- 複数スタンプの一括管理
- メイン画像・タブ画像・申請ZIPの生成
- LINE Creators Marketへの自動アップロード
