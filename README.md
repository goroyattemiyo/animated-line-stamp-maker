# Animated LINE Stamp Maker

AIが生成した8フレームの画像シートを、LINEアニメーションスタンプ用のAPNGへ整形する制作支援ツールです。

## 目的

本プロジェクトは、画像生成AIとローカル整形アプリの役割を分離します。

```text
参照キャラクター画像
  ↓
専用GPTで4列×2行・8フレームのシートを生成
  ↓
本アプリで分割・補正・プレビュー
  ↓
LINEアニメーションスタンプ用APNGを出力
```

GPTはフレーム素材の生成を担当し、本アプリは機械的に再現可能な後処理を担当します。

## 基本入力仕様

- PNG画像1枚
- 横4列×縦2行
- 合計8フレーム
- フレーム順は左上から右へ01〜04、下段左から右へ05〜08
- 各セルは同一サイズ
- 背景は透明
- 各セル外周に、後で除去する位置合わせ用マーカーを配置可能
- 画像内にフレーム番号を描かない

## MVP

1. 4列×2行シートの読み込み
2. 固定グリッドによる8フレーム分割
3. マーカー専用外周の除去
4. フレーム順の確認・並べ替え
5. フレームごとの表示時間設定
6. ループプレビュー
7. 連番PNG出力
8. APNG出力
9. LINE向け基本仕様チェック

## 設計方針

- 固定グリッドを主判定とし、トンボ・マーカーは補助に使う
- 元画像を破壊せず、設定をプロジェクトデータとして保存する
- 高度なAI補間より先に、分割とAPNG出力の確実性を優先する
- デスクトップ版を先行し、将来Web版も検討する
