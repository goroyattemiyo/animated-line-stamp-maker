# Animated LINE Stamp Maker

AIが生成した8フレームの画像シートを、LINEアニメーションスタンプ用のAPNGへ整形するローカル制作支援ツールです。

## 目的

画像生成AIと整形アプリの役割を分離します。

```text
参照キャラクター画像
  ↓
専用GPTで横4列×縦2行・8フレームのシートを生成
  ↓
本アプリで分割・補正・プレビュー
  ↓
LINEアニメーションスタンプ用APNGを生成・再検査
```

GPTはフレーム素材の生成を担当し、本アプリは機械的に再現可能な後処理を担当します。

## 基本入力仕様

- PNG画像1枚
- 横4列×縦2行
- 合計8フレーム
- フレーム順は上段左から01〜04、下段左から05〜08
- 各セルは同一サイズを基本とする
- 背景は透明
- 各セル外周に、後で除去する位置合わせ用L字マーカーを配置可能
- 画像内にフレーム番号を描かない

## アプリの基本機能

1. PNGの安全な読み込みと検査
2. 4列×2行の固定グリッド分割
3. 分割境界の手動調整
4. マーカー領域の除去
5. 全フレーム共通キャンバスの生成
6. フレームごとの位置調整
7. タイムライン・表示時間・ループ編集
8. 透明背景を含むプレビュー
9. LINE向け寸法への変換
10. APNG生成
11. 生成APNGの独立再検査
12. プロジェクト保存

## 設計方針

- 固定グリッドを主判定とし、トンボ・マーカーは補助に使う
- 元画像を上書きしない
- 同じ入力と設定から同じ出力を再現できる構成にする
- 自動位置補正を勝手に適用しない
- APNGを書き出した後に、フレーム数・時間・ループ・透過を再検査する
- 主要処理はオフラインで完結する
- Windows版を先行する
