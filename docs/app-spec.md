# アプリケーション仕様

## 1. 目的

専用GPTなどで生成された「横4列×縦2行・合計8フレーム」のPNGシートを読み込み、LINEアニメーションスタンプ用のAPNGへ整形する。

本アプリは、画像生成そのものではなく、次の再現可能な後処理を担当する。

- フレーム分割
- マーカー領域除去
- 位置ずれ確認・補正
- フレーム順編集
- 表示時間設定
- ループプレビュー
- APNG出力
- LINE仕様チェック

## 2. 対象ユーザー

- ChatGPTなどでアニメーション用フレームを生成するLINEスタンプ制作者
- イラストソフトで連番画像を作成する制作者
- APNG変換やLINE向け仕様調整を一括化したい制作者

入力元を特定のAIサービスへ限定しない。

## 3. 入力仕様

### 3.1 MVP入力

- PNG画像1枚
- 横4列×縦2行
- 合計8セル
- 各セルは原則同一サイズ
- 背景は透過を推奨

### 3.2 許容する差異

- 画像サイズが4列・2行で割り切れない
- マーカーの一部が欠損している
- 数ピクセル程度のセル境界誤差
- 透明背景に微量の半透明画素が残る
- キャラクター位置がフレームごとに少しずれる

### 3.3 エラーと警告

処理停止エラー：

- 画像を読み込めない
- PNGとして復号できない
- 幅または高さが極端に小さい
- 8分割後のセルサイズが実用範囲を下回る

警告して続行：

- マーカーを検出できない
- 透過が存在しない
- 8フレームの描画量が大きく異なる
- キャラクター位置の差が大きい
- 出力容量がLINE向け上限を超える

## 4. 分割アルゴリズム

### 4.1 基本方針

固定グリッドを主判定とする。

```text
cellWidth  = imageWidth / 4
cellHeight = imageHeight / 2
```

割り切れない端数は、最後の列・行へ集約せず、境界座標を比率から算出して丸める。

```text
x0 = round(width * col / 4)
x1 = round(width * (col + 1) / 4)
y0 = round(height * row / 2)
y1 = round(height * (row + 1) / 2)
```

これにより全画素を重複・欠落なく8セルへ割り当てる。

### 4.2 フレーム順

```text
01 02 03 04
05 06 07 08
```

内部インデックスは0始まりでもよいが、UIと出力ファイル名は1始まりとする。

### 4.3 マーカー補正

MVPでは固定グリッド分割を必須実装とし、マーカー検出は補助機能とする。

検出時の候補処理：

1. 各セル外周だけを探索する
2. 黒に近い連結成分を抽出する
3. L字に近い水平線・垂直線の組を探す
4. 期待位置からの差を境界補正候補として表示する
5. 自動適用せず、補正量が閾値内の場合だけ提案する

誤検出を避けるため、キャラクター中央領域は探索対象にしない。

## 5. マーカー領域除去

### 5.1 MVP方式

各セルの外周を比率指定で除去する。

初期値：

- 上下左右それぞれセル短辺の6%

UIでは次を選択可能にする。

- 0%
- 4%
- 6%
- 8%
- カスタム

ピクセル固定ではなく比率を基本とし、異なる生成解像度へ対応する。

### 5.2 安全確認

除去前後の画像を重ねて表示し、非透明画素が切れた場合は警告する。

マーカー除去によって本体が欠ける場合、ユーザーはセルごとまたは全セル共通で余白を戻せる。

## 6. 透明領域と共通トリミング

各フレームを個別に最小トリミングすると基準位置が変わり、再生時に揺れて見える。そのため、次の方式を採用する。

1. マーカー領域除去後の各フレームからアルファ値が閾値以上の画素を抽出
2. 全8フレームの描画領域を合成
3. 合成結果の共通外接矩形を算出
4. 全フレームを同一矩形で切り出す
5. 必要な安全余白を追加する

アルファ閾値の初期値は8/255程度とし、半透明ゴミの影響を抑える。

## 7. 位置合わせ

### 7.1 目的

画像生成時に発生した、意図しない全体移動によるガタつきを軽減する。

### 7.2 MVP補正

- 補正なし
- 描画領域中心
- アルファ重心
- 足元基準

初期値は「補正なし」とする。自動補正で意図した身体の動きを消す危険があるため、ユーザーがプレビューを見ながら適用する。

### 7.3 補正量制限

セル短辺に対する最大移動率を設定する。

- 弱：1%
- 標準：2%
- 強：4%

上限を超える補正は自動適用しない。

### 7.4 手動補正

フレームごとにX・Yを1px単位で調整できるようにする。複数フレーム選択への一括適用も将来対応する。

## 8. タイムライン

### 8.1 基本機能

- 8フレームのサムネイル表示
- ドラッグによる並べ替え
- フレーム複製
- フレーム削除
- 元順へ戻す
- 逆再生
- 往復列の生成

ただしLINE向け出力時は、最終フレーム数が5〜20の範囲にあるか確認する。

### 8.2 表示時間

フレームごとにミリ秒で保持する。

初期値：125ms × 8フレーム = 1秒

プリセット：

- 1秒
- 2秒
- 3秒
- 4秒

合計時間が整数秒にならない場合は警告する。

### 8.3 ループ回数

- 1〜4回
- 合計再生時間が4秒を超えないことを検証する

## 9. プレビュー

### 9.1 必須機能

- 再生
- 停止
- 先頭へ戻る
- 1フレーム送り
- 再生速度の実時間反映
- ループ回数の反映

### 9.2 背景確認

- 透明市松
- 白
- 黒
- 明るいグレー
- 任意色

白フチ、半透明ゴミ、文字の視認性を確認できるようにする。

### 9.3 差分確認

前フレームとの半透明重ね合わせ表示を用意し、意図しない全体移動や形状変化を確認しやすくする。

## 10. 出力

### 10.1 連番PNG

```text
frame_01.png
frame_02.png
...
frame_08.png
```

### 10.2 APNG

- 拡張子 `.png`
- フレーム遅延を保持
- ループ回数を保持
- 透過を保持

### 10.3 LINE向け基本検証

アプリ内ルールは設定ファイル化し、LINE公式仕様の変更へ追従できるようにする。

MVPで確認する項目：

- APNGである
- フレーム数が5〜20
- 1ループが1、2、3、4秒のいずれか
- ループ回数が1〜4
- 合計再生時間が4秒以内
- 最大寸法以内
- RGB
- 背景透過
- ファイル容量上限以内

公式仕様は実装時に再確認し、コードへ固定値を散在させない。

## 11. プロジェクト保存

元画像を埋め込まず、参照パスと非破壊設定をJSONで保存する案を基本とする。

```json
{
  "schemaVersion": 1,
  "source": {
    "path": "sheet.png",
    "sha256": "..."
  },
  "layout": {
    "columns": 4,
    "rows": 2,
    "order": "row-major"
  },
  "markerTrim": {
    "mode": "ratio",
    "top": 0.06,
    "right": 0.06,
    "bottom": 0.06,
    "left": 0.06
  },
  "frames": [
    { "sourceIndex": 0, "offsetX": 0, "offsetY": 0, "durationMs": 125 }
  ],
  "animation": {
    "loopCount": 4
  }
}
```

元画像のハッシュが変わった場合は警告する。

## 12. UI構成

MVPは1画面のステップ型UIを基本とする。

```text
[1 読み込み]
  ↓
[2 分割・マーカー除去]
  ↓
[3 フレーム調整]
  ↓
[4 プレビュー]
  ↓
[5 検証・出力]
```

主要領域：

- 左：入力画像と分割境界
- 中央：現在フレームの編集ビュー
- 下：タイムライン
- 右：設定とLINE仕様チェック

## 13. 技術候補

第一候補：

- Electron
- React
- TypeScript
- Vite
- Sharp
- APNGエンコード対応ライブラリ
- Vitest
- Playwright

技術選定時の確認事項：

- Electron環境でAPNGのフレーム遅延と透過を正しく保持できること
- Windows向け配布が容易であること
- ネイティブ依存を含む場合のビルド再現性
- ライセンス条件

APNGライブラリは実装開始時に最新状況を再調査して決定する。

## 14. 非機能要件

- 元画像を上書きしない
- オフラインで主要処理を完結する
- 画像を外部サービスへ送信しない
- Windowsを最初の正式対応環境とする
- 8フレームの通常操作を待ち時間なく実行できる
- 操作の取り消し・やり直しを将来追加可能なデータ構造にする

## 15. MVP受け入れ基準

- 任意解像度の4列×2行PNGを8枚へ分割できる
- マーカー領域を一括除去できる
- 8フレームを順番どおり表示できる
- フレーム時間とループ回数を設定できる
- プレビューが設定どおり再生される
- 連番PNGを書き出せる
- APNGを書き出せる
- LINE向け基本チェック結果を表示できる
- 元画像が変更されない
