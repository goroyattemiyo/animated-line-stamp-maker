# 開発ロードマップ

## 方針

最初からAI補間やLINE申請ZIPまで実装せず、次の順で確実に積み上げる。

```text
生成仕様を固定
  ↓
固定グリッド分割
  ↓
マーカー除去
  ↓
プレビュー
  ↓
APNG出力
  ↓
LINE仕様検証
  ↓
一括処理・申請支援
```

## Phase 0: 仕様固定

### 作業

- GPT出力契約を確定
- 横4列×縦2行の表現へ統一
- L字マーカーの目的と扱いを確定
- サンプルシートを複数作成
- 良品・不良品の判定基準を作成

### 成果物

- `docs/gpt-spec.md`
- `docs/app-spec.md`
- テスト用入力画像
- 期待する8分割結果

### 完了条件

- 同じGPT指示で複数回生成し、固定グリッドで8分割できる
- マーカー欠損時もアプリ側の処理方針が決まっている
- キャラクター一貫性の許容範囲を目視で判断できる

## Phase 1: プロジェクト初期化

### 作業

- Electron + React + TypeScript + Vite構成を作成
- ESLint、Prettier、Vitestを導入
- Electronメイン・プリロード・レンダラーを分離
- ローカルファイル読込と保存の安全なIPCを実装
- Windowsで開発起動を確認

### 完了条件

- `npm install`
- `npm run dev`
- `npm test`

が正常に動作する。

## Phase 2: 固定グリッド分割

### 作業

- PNGのドラッグ&ドロップ
- 画像情報表示
- 4列×2行の境界オーバーレイ
- 比率ベースで8セルへ分割
- サムネイル表示
- 連番PNG出力

### テスト

- 幅・高さが4と2で割り切れる画像
- 端数が発生する画像
- 透明PNG
- 非透明PNG
- 高解像度・低解像度画像

### 完了条件

- 入力画像の全画素を重複・欠落なく8セルへ分割できる
- 表示順が01〜08で正しい
- 連番PNGが出力できる

## Phase 3: マーカー領域除去

### 作業

- 外周除去率の設定
- 初期値6%
- 除去前後プレビュー
- 描画画素切断の警告
- 全セル共通設定
- リセット

### 完了条件

- L字マーカーを一括で除外できる
- キャラクターが欠けた場合にユーザーが調整できる
- マーカーがない画像でも処理できる

## Phase 4: 共通トリミングと位置調整

### 作業

- アルファ領域抽出
- 全フレーム共通外接矩形
- 安全余白追加
- 補正なし
- 描画領域中心補正
- アルファ重心補正
- 手動X/Y調整

### テスト

- 手だけ動くケース
- キャラクター全体が数pxずれるケース
- 大きくジャンプするケース
- 半透明エフェクトがあるケース

### 完了条件

- 個別トリミングによるガタつきを発生させない
- 意図した動きを残したまま、不要な全体ずれを軽減できる

## Phase 5: タイムラインとプレビュー

### 作業

- フレーム並べ替え
- フレーム複製・削除
- 逆再生
- 往復列生成
- フレームごとの表示時間
- 1〜4秒プリセット
- 1〜4ループ
- 白・黒・市松背景プレビュー

### 完了条件

- 設定した順序と時間で再生される
- 合計再生時間を常時表示する
- LINE向け条件違反を即時警告する

## Phase 6: APNG出力

### 作業

- APNGエンコーダ選定
- 透過保持
- フレーム遅延保持
- ループ回数保持
- 出力後の再読込検証
- ファイル容量表示

### テスト

- ブラウザ表示
- アプリ内再読込
- フレーム数確認
- 遅延時間確認
- ループ回数確認
- アルファ確認

### 完了条件

- 出力APNGを再読込して、設定値と一致する
- 通常PNGとして誤出力されない
- 透過が失われない

## Phase 7: LINE仕様チェッカー

### 作業

- 仕様値を設定ファイルへ分離
- フレーム数チェック
- 寸法チェック
- 再生時間チェック
- ループ回数チェック
- 容量チェック
- RGB・透過チェック
- 1フレーム目確認メッセージ

### 完了条件

- エラー、警告、合格を区別して表示できる
- 仕様値更新時に画像処理コードを変更せず対応できる

## Phase 8: プロジェクト保存

### 作業

- `project.json`保存
- 再読込
- 元画像SHA-256照合
- 非破壊設定の復元
- 最近使ったプロジェクト

### 完了条件

- アプリ再起動後も編集を再開できる
- 元画像が差し替わった場合に警告する

## Phase 9: 一括制作支援

### 候補機能

- 8個・16個・24個のスタンプ一括管理
- フォルダ単位の入力
- 全スタンプ共通設定
- メイン画像生成
- トークルームタブ画像生成
- 申請用ファイル名変換
- ZIP出力
- 制作進捗管理

## Phase 10: 高度機能

MVP完了後に検討する。

- マーカー自動検出
- 顔・胴体・足元基準の自動位置合わせ
- 透過ゴミ検出
- フレーム間差分ヒートマップ
- 容量超過時の自動最適化
- フレーム補間
- 部位マスクによる局所補正
- Web版
- macOS版

## 優先順位

### 必須

- 固定グリッド分割
- マーカー除去
- タイムライン
- プレビュー
- APNG出力
- LINE基本チェック

### 重要

- 共通トリミング
- 手動位置調整
- プロジェクト保存

### 後回し

- 高度な自動位置合わせ
- AI補間
- LINE申請ZIPの完全自動化
