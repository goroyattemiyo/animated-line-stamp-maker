# 開発ロードマップ

本書は実装順と完了条件だけを管理する。機能仕様は `docs/app-spec.md` を正本とする。

## Phase 1：Web MVP起動

- GitHub Pagesで起動
- PNG選択とドラッグ＆ドロップ
- Canvas表示
- 外部CDN依存を廃止

完了条件：

- ページ表示後に「準備完了」が表示される
- 画像未読込でもJavaScriptエラーが発生しない

## Phase 2：1枚PNGから8フレーム生成

- 透明画素の検査
- 不透明画素の境界検出
- 透明余白の自動除外
- 320×270pxへの配置
- 8フレーム生成

完了条件：

- 1枚のPNGから8枚のCanvasが生成される
- タイムラインに8枚表示される

## Phase 3：動きテンプレート

- ぴょこ
- ゆらゆら
- ぷるぷる
- ぺこり
- ぽよん
- ふわふわ
- くるり

完了条件：

- テンプレート切り替えが即座に8フレームへ反映される
- 最初と最後の接続が大きく破綻しない

## Phase 4：調整とプレビュー

- 動きの強さ
- 画像サイズ
- X位置
- Y位置
- 背景切り替え
- 再生・停止・フレーム送り
- 1〜4秒のループ時間
- 合計4秒以内の有限ループ

完了条件：

- すべての設定がプレビューとタイムラインへ反映される
- 指定ループ回数で停止する

## Phase 5：APNG出力

- CompressionStreamによる圧縮
- PNGチャンク生成
- CRC32付与
- 8フレームAPNG生成
- ダウンロード

完了条件：

- ChromeとEdgeでAPNGを保存できる
- 保存ファイルを対応ブラウザで再生できる

## Phase 6：出力再検査

- acTL検査
- fcTL数検査
- ループ回数検査
- 1MB容量検査

完了条件：

- フレーム数またはループ回数が一致しない出力を完成扱いにしない
- 1MB超過を明確に表示する

## Phase 7：実機検証と調整

- 実際のキャラクターPNGで確認
- 各テンプレートの強さ初期値調整
- 画像切れ確認
- 白・黒背景での縁確認
- モバイル表示確認

完了条件：

- 代表的な縦長・横長・正方形キャラで破綻しない
- LINEへ申請可能なAPNGを1個完成できる

## v1後の候補

- 文字やエフェクト追加
- 腕・顔などの手動パーツ指定
- 瞬き・口パク
- 複数スタンプ一括出力
- メイン画像・タブ画像
- LINE申請用ZIP
